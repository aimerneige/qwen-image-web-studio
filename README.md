# Qwen-Image 2.1 Web Studio

基于 **Material Design 3 (MD3)** 设计风格的 Qwen-Image 2.1 简易图像生成 Web 应用。

---

## 🌟 核心特性

- **Material Design 3 现代界面**：遵循 MD3 官方规范（Tonal Palette、动态 Surface 层级、圆角卡片、药丸按钮、线性进度条与深浅色模式切换）。
- **硬件独占互斥锁（单任务保护）**：Qwen-Image 2.1 模型极度消耗硬件资源。后端采用双重互斥锁（`asyncio.Lock` 与状态守卫），**严格限制同一时刻仅允许一个生成任务执行**。并发请求将受到友好拦截并提示排队状态，防止显存与内存溢出崩溃。
- **极致显存保护（Sequential CPU Offload）**：针对硬件瓶颈开启 Diffusers 逐层卸载机制，空闲时绝大部分模型权重常驻系统内存，GPU 闲置显存占用维持在极低水位（~1.7GB），按需分层调度推理。
- **实时步进流式反馈（SSE）与随时提前终止**：基于 Server-Sent Events 实现毫秒级进度同步，页面实时显示当前推理阶段、批次轮次（第 X/Y 张）、去噪采样步数（Step X/Y）、进度百分比、已耗时与预估剩余时间（ETA）；支持**随时提前终止**，无论是单图还是连续批次生成均可即时打断，已生成的图片自动完整保留入库，未开始的轮次自动跳过，并立即释放 GPU 硬件锁。
- **动静合一单端口部署**：React + Vite 前端构建出的生产静态资源直接由 FastAPI 后端统一托管，开箱即用，无需配置复杂的 Nginx 反向代理。
- **生成数量与连续顺序生成**：支持指定相同提示词连续生成多张图片（如 1、2、3、4、8 张），严格顺序执行防止显存并发溢出；生成过程中种子智能递增以保证多样性，每张图片生成完毕即刻推送预览并存入 SQLite，支持随时提前终止。
- **文生图、单图与多图参考全支持（Qwen3-VL 多模态引导）**：
  - **多图参考输入**：支持单张或多张图片上传（文件多选、拖拽或剪贴板 Ctrl+V 粘贴），自动显示序号角标（图 1、图 2、...）与独立删除；提示词中可直接指定“让图1的角色穿上图2的衣服”或“让图1的角色置身于图2的场景中”。
  - **灵感变换预设**：内置单图与多图协同灵感预设（角色融入场景、服装迁移、画风迁移、多主体协同）。
  - **自适应画幅与对比**：上传参考图后自动自适应原始比例输出，并支持一键对比查看所有参考原图与生成图。
- **SQLite 纯净持久化存储**：采用 Python 标准库内置 `sqlite3`（零额外依赖），任务完成后将输入参考图（单图/多图列表）、生成图片、完整提示词、负向词、随机种子、推理步数、生成耗时（秒）及创建时间完整存入本地 `history.db`；彻底废弃无 prompt 旧文件扫描回退，仅展示纯净真实的历史数据，服务重启数据永不丢失。
- **便捷工作流与历史记录**：
  - 内置快捷灵感预设 Chip（Q版手办、赛博朋克、新海诚唯美、电影写实、水彩国风、多图组合等）。
  - 高级推理参数可折叠调节（步数 Slider、画幅比例/分辨率、随机种子控制、负向提示词）。
  - **历史记录单条安全删除**：每个历史卡片与生成预览栏均可独立删除指定历史记录，删除时自动清理磁盘上对应的输出图片与临时引用图文件，防止磁盘占用膨胀。

## 🚀 启动指南

### 1. 环境准备 (首次运行或全新克隆)

- **Python 依赖**：
  ```bash
  uv sync
  ```
- **前端构建**（如需重新生成静态资源）：
  ```bash
  cd frontend && npm install && npm run build && cd ..
  ```

### 2. 启动 Web 服务

服务默认监听并在单端口托管所有前端与 API 路由：

```bash
# 推荐方式：使用当前虚拟环境启动
.venv/bin/python server.py

# 或者使用 uv 启动
uv run python server.py
```

终端将显示启动就绪信息：
```text
==================================================
🚀 Qwen-Image 2.1 Web Studio 正在启动...
📡 服务地址: http://localhost:8000
🔒 硬件互斥锁: 已激活 (单任务独占)
⚡ 显存保护: Sequential CPU Offload 已就绪
==================================================
```

### 3. 访问与使用

- 打开浏览器访问：👉 **[http://localhost:8000](http://localhost:8000)**
- **自定义端口/主机**：可以通过环境变量指定：
  ```bash
  PORT=8080 HOST=0.0.0.0 .venv/bin/python server.py
  ```
- **停止服务**：在运行服务的终端窗口直接按下 `Ctrl + C` 即可平美关闭。

## 🛠️ 前端二次开发与构建

如需对前端界面（[`frontend/src`](frontend/src)）进行修改或定制：

```bash
# 进入前端目录
cd frontend

# 安装依赖
npm install

# 本地热重载开发调试（API 代理到 8000）
npm run dev

# 构建生产静态资源（输出至 frontend/dist，后端将自动挂载）
npm run build
```

## 📁 目录结构

```text
├── backend/
│   ├── app.py              # FastAPI 应用、路由定义、SSE 事件流与静态文件托管

│   ├── src/
│   │   ├── App.tsx         # MD3 风格主界面（输入、实时进度、预览与历史相册）

│   ├── dist/               # Vite 构建出的生产静态文件

├── pyproject.toml          # Python 依赖配置文件
```
